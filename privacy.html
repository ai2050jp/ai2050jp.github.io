AI2050 uploader プライバシーポリシー

制定日: 2026年9月26日

AI2050 uploader(以下「本ツール」)は、YouTubeチャンネル「AIが描く2050年」(https://www.youtube.com/@ai2050jp)の運営者が、自分のチャンネルに動画を予約投稿するためだけに使う個人用のツールです。本ツールは一般には公開・配布していません。

1. 利用する情報

本ツールは、Google の OAuth 認証で運営者本人が許可した範囲で、YouTube Data API を通じて次の情報を扱います。

  • 運営者本人のチャンネルの基本情報(チャンネル名など)
  • 運営者本人がアップロードする動画、タイトル、説明文、サムネイル画像
  • 運営者本人のチャンネルの動画の公開状態・公開予約日時

2. 利用目的

上記の情報は、運営者本人のチャンネルへの動画のアップロード、予約公開の設定、サムネイルの設定、およびそれらが正しく行われたかの確認のためだけに使います。

3. 保存と第三者提供

  • 認証情報(アクセストークン)は運営者本人のパソコンの中にだけ保存します。
  • 取得した情報を第三者に提供・販売することはありません。広告や分析のために利用することもありません。
  • 他のユーザーやチャンネルの情報は扱いません。

4. Google のサービスについて

本ツールは YouTube API サービスを利用しています。YouTube の利用規約(https://www.youtube.com/t/terms)および Google のプライバシーポリシー(https://policies.google.com/privacy)が適用されます。

5. アクセス許可の取り消しとデータの削除

  • 本ツールへのアクセス許可は、Google アカウントのセキュリティ設定(https://security.google.com/settings/security/permissions)からいつでも取り消せます。
  • 本ツールが保存するのは、運営者本人のパソコン内の認証情報(アクセストークン)と、アップロードした動画のID・予約日時の記録だけです。これらは、アクセス許可を取り消したとき、または本ツールの利用をやめたときに、パソコンから削除します。
  • YouTube から取得したデータを30日を超えて保存することはありません(動画のID・予約日時の記録を除く。これは運営者本人がアップロードした自分の動画の記録です)。

6. お問い合わせ

本ポリシーに関するお問い合わせは、YouTubeチャンネル「AIが描く2050年」の概要欄に記載の連絡先までお願いします。
