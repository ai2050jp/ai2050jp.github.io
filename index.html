AI2050 uploader

YouTubeチャンネル「AIが描く2050年」(https://www.youtube.com/@ai2050jp)の運営者が、自分のチャンネルに完成したショート動画を予約投稿するための個人用ツールです。一般には公開・配布していません。

できること

  • 自分のチャンネルへの動画のアップロード
  • タイトル・説明文・サムネイルの設定
  • 公開日時の予約(毎日20:00)

本ツールは YouTube API サービスを利用しています。

  • YouTube 利用規約: https://www.youtube.com/t/terms
  • Google プライバシーポリシー: https://policies.google.com/privacy
